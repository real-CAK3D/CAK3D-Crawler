Use your computer's AI from your phone

For Arachnotes on Android. Free and private: your text goes to your own computer, not to an AI company.

1. Get Ollama and a model

  1. Install Ollama from ollama.com/download.
  2. Download a model. In a terminal (Command Prompt on Windows), run ollama pull qwen3. Smaller computers can use ollama pull qwen3:4b or ollama pull gemma3.

2. Let your phone reach it

Out of the box, Ollama only answers the computer it runs on. The setup below lets devices on your home Wi-Fi reach it too, then shows the address to type into the app.

Using a recent Ollama app? You can also turn on Expose Ollama to the network in its Settings. The setup below still helps on Windows, because it also lets Ollama through the firewall.

  1. Download the Windows setup
  2. Open the downloaded file. If Windows says it protected your PC, choose More info, then Run anyway. Then choose Yes when it asks to make changes. It needs that to allow Ollama through the firewall.
  3. If it says your network is set to Public, answer Y to mark your home Wi-Fi as Private.
  4. It restarts Ollama and shows your computer's address, like 192.168.1.20.

To undo it later, open Command Prompt in your Downloads folder and run ollama-windows.bat undo.

  1. Open Terminal (in Applications → Utilities) and paste: 
    curl -fsSL __SITE__connect/ollama-mac.sh | bash
  2. If macOS asks whether Ollama may accept incoming network connections, choose Allow.
  3. It shows your Mac's address, like 192.168.1.20.

To undo it: curl -fsSL __SITE__connect/ollama-mac.sh | bash -s undo

  1. In a terminal, paste: 
    curl -fsSL __SITE__connect/ollama-linux.sh | sh
    It asks for your password to update Ollama's service settings.
  2. It shows your computer's address, like 192.168.1.20.

To undo it: curl -fsSL __SITE__connect/ollama-linux.sh | sh -s undo

3. Connect the app

  1. Make sure your phone is on the same Wi-Fi as your computer.
  2. In Arachnotes, open Settings → Research → Your AI and choose Ollama on my computer.
  3. Type the address the setup showed, or tap Find my computer.
  4. Tap Load models, pick one, then Save and Test it.

Your computer needs to be on with Ollama running whenever you use the AI from your phone. Summaries and answers from a local model take longer than from an online AI, especially on a computer without a graphics card.

LM Studio instead

  1. In LM Studio, open the Developer tab, load a model, and start the server.
  2. In the server settings, turn on Serve on Local Network and Enable CORS.
  3. In the app, choose LM Studio on my computer and type your computer's address. You can find it in LM Studio's server panel, or tap Find my computer.

Is this safe?

The setup lets devices on your home network use Ollama. On Windows the firewall rule covers private networks only, and on Linux it allows home network addresses only. Use it on a network you trust, not on public Wi-Fi, and use the undo steps above when you no longer need it. Ollama doesn't read your files. It only answers the requests sent to it.
